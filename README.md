# OpenPathFinder — Adobe Illustrator 开放路径检查插件

**版本 v1.1.0** · Copyright (C) 2026 GilSophia. All rights reserved.

检查当前所选对象中所有未闭合的开放路径（支持组、复合路径内部的子路径），
并在画布上用**橙色荧光线条**直接标注断口位置。

## 功能

- 一键检测所选对象中的开放路径（递归检查组、复合路径、子路径）
- 橙色荧光粗线高亮开放路径本体
- 橙色圆圈标记两个断口端点
- 橙色虚线连接两个端点（直观显示缺口方向与大小）
- 可选的路径编号（与结果列表一一对应）
- 结果列表显示每条开放路径的锚点数、长度、断口距离、端点坐标
- 标注统一放在独立的 “★开放路径标记” 图层，可一键清除，原稿不受影响
- 支持**隔离模式（Isolation Mode）**下直接执行，不会报 “Cannot add a new layer” 错误；
  隔离模式下标注自动暂存到当前图层，仍可用“清除标注”一键清理
- 标注坐标按对象的最终变换计算，组被缩放、旋转后依然准确
- 面板自动记忆选项勾选状态，适配 Illustrator 深色/浅色主题

## 安装

1. 双击运行 `OpenPathFinder_Setup.exe`；
2. 点击「安装」，等待完成提示；
3. 重启 Adobe Illustrator；
4. 打开菜单：**窗口 → 扩展功能 → OpenPathFinder**
   （旧版 Illustrator 为：**窗口 → 扩展 → OpenPathFinder**）。

安装程序会自动：

- 复制插件到 `C:\Users\<用户名>\AppData\Roaming\Adobe\CEP\extensions\OpenPathFinder`
- 自动移除旧版本目录（如有）
- 启用 CEP 扩展调试模式：仅写入当前用户注册表
  `HKCU\Software\Adobe\CSXS.6 ~ CSXS.12` 的 `PlayerDebugMode=1`
  （这是加载未签名扩展的 Adobe 标准机制，可随时删除）
- 安装程序内也提供「卸载」按钮

本安装包为单一文件，无需其他文件即可完成安装。

> 系统要求：Adobe Illustrator CC 2015 及以上（Windows）。
> 若 Windows 提示“未知发布者”，选择“仍要运行”即可（安装包未做数字签名）。

## 使用

1. 用选择工具选中要检查的对象（可多选）。
2. 在面板中点击 **检查并标注**。
3. 画布上立即出现橙色标注，面板结果区列出每条开放路径的详细信息：
   - `#序号 · 锚点数 · 长度 · 断口距离 pt`
   - `端点 (x, y) → (x, y)`
4. 修复断口后，点击 **清除标注**，或直接删除 “★开放路径标记” 图层。

## 标注图例

| 标注 | 含义 |
| --- | --- |
| 橙色荧光粗线 | 开放路径本体 |
| 橙色圆圈 | 开放路径的两个端点（断口位置） |
| 橙色虚线 | 两端点之间的连线，显示缺口方向与大小 |
| 数字 | 路径编号（可选，与结果列表对应） |

## 常见问题

- **点检查没反应/提示请选择对象**：面板只检查“当前选择对象”，不会扫描整个文档（避免误标）。
- **在隔离模式下使用**：可以直接执行。隔离模式下 Illustrator 不允许脚本新建图层，
  插件会自动把标注暂存到当前图层并命名标记，点“清除标注”即可全部清理。
- **结果里显示“坐标为近似值”**：个别特殊对象（如复合路径中的个别子路径）无法单独
  复制定位，此时端点坐标仅供参考，但开放路径本身仍会被列出。
- **标注会打印出来吗**：标注是普通图形，会参与打印/导出。交付前请点击“清除标注”，
  或隐藏/删除 “★开放路径标记” 图层。
- **面板不出现**：确认已执行安装并重启了 Illustrator；查看“窗口 → 扩展功能”菜单。
